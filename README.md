# Basic Calculator

A small calculator project built with **HTML5, CSS3 and vanilla JavaScript** as part of my Web Development internship practice.

The idea was to keep it simple to use, easy to read, and comfortable on both desktop and mobile screens.

## Features

- Addition, subtraction, multiplication and division
- Decimal number support
- Clear (`AC`) and delete (`DEL`) controls
- Keyboard input
- Handles division by zero
- Responsive layout
- No external libraries or frameworks
- Calculations handled in JavaScript without `eval()`

## Built With

- **HTML5** for the page structure
- **CSS3** for the layout, styling and responsive design
- **JavaScript** for calculator operations and event handling

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

You can also open the folder in VS Code and use the Live Server extension.
